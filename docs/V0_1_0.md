更新：2026-10-15。版本标签 [v0.1.0](https://github.com/medhlab/OHIF-NIFTI/tree/v0.1.0) 指向 `090f0fbf1473c2c895753b4857716cf2c0c6b93e`，即 PR #6 合并提交。本文补充于标签发布后，不移动标签。

## 产品范围

面向单 CT 的 Finding / Entity 标注，没有独立审核角色，也没有旧系统数据迁移要求。
Finding 是报告或影像发现，Entity 是可定位和编辑的对象/区域；二者都不等同于病灶。
多个 Finding 可以共享同一 Entity，各自保留原文证据。界面已移除“选择共享 Entity”入口，底层关系与导入共享能力保留。
类别定义在 Finding；当前 Entity 显示关联类别，不另建固有类别字段。F1-E1 是显示别名，删除/解除关联后可重新排序，UUID 才是持久身份。

## 已实现

| 范围 | 当前行为 |
| --- | --- |
| 数据组织 | 数据集列表、split 筛选、搜索分页；ReXGroundingCT 的 train/val 属于同一数据集，计数只表示已导入病例 |
| 报告 | 原文与 Finding 描述分离；已有模型结果导入；流水线按原文顺序整理 Finding；缺失报告不以 Finding 文本伪造原文 |
| 工作台 | Finding 默认折叠且单项展开；原文联动居中；搜索/新增/类别修改行内化；模块间可拖动高度 |
| Entity | 新增、定位、改名、删除、解除关联；颜色图例与空 mask 虚线提示；点击 Finding 加载全部已保存 mask |
| 编辑 | 新增 Entity 或点击编辑图标进入；一次一个 mask；顶部手工/AI 工具互斥；保存继续编辑，退出保留未保存结果 |
| nnInteractive | 点/框/涂画提示、提示管理、当前目标精修、过期请求保护；自动应用或手动应用提示 |
| 存储 | 每 Finding 一个多标签体积；同一 Finding 内不允许 Entity 重叠；共享 Entity 同步；按 Entity 保存版本并支持重开 |
| 病例状态 | 病例名右侧标记完成；未保存/空 mask 等条件会阻止完成；整体进度不放在单个 Entity 区域 |
| 结构 | 已有 TotalSegmentator 结果及其标签映射作为只读辅助层；不占 Entity 标注完成分母 |
| 图像 | 默认肺窗；渐进加载完整 CT，随导航更新优先级；底部显示加载文字和百分比 |
| 预加载/缓存 | 当前图像加载完成后预加载后两例；共用 512 MiB 压缩磁盘缓存，当前优先、历史 LRU 淘汰；刷新恢复位置，菜单显示占用并清理 |

不同 Finding 的标签体积可以存在空间重叠。同一 Finding 内导入重叠会拒绝覆盖已有标注。
普通网页原图上传仍只接收三维 NIfTI；ReX 原始四维 `(Finding,X,Y,Z)` 格式通过专用导入器处理，见 [导入说明](../deploy/datasets/rexgroundingct/IMPORT.md)。

## 验收与部署

- v0.1.0 最终前端完整构建及 111 项回归通过，3 个已有 webpack 警告。不是所有历史前后端测试数量的合计。
- 真实 CT 264 层刷新后全部磁盘命中，服务端新增 frame 请求为 0；清理期间的旧请求不会重新填充缓存。
- 单 CT、两个 mask 的前端导入处理由 5.62 秒降至 1.88 秒；多轮首个 Entity 定位 1.3–2.5 秒、全部就绪 3.1–4.0 秒。受网络、浏览器与 worker 调度影响，不是 GPU 渲染完成计时或全数据集基准。
- 手工绘制、保存、重开与共享目标保护通过；直接跳转后图像、层号及滚动条同步。
- nnInteractive 已在此前阶段做真实模型加载、GPU 推理和保存重开验收；最后缓存/性能迭代沿用回归，没有重新跑 GPU 推理。
- 最后核验的 rtx4500 隔离预览镜像是 `ohif-nifti-rtx4500-viewer:finding-fast-3200ed1655`。标签发布不代表正式服务已升级；正式 viewer 与后端在最后一轮未变更。
- 公共产物：rtx4500 `/home/ant/projects/OHIF-NIFTI/releases/finding-fast-20261015/`，包含构建、快照、验收和回退配置。实时入口及历史证据见 [基础设施交接](INFRASTRUCTURE_HANDOFF.md)。

## 尚未完成或不作保证

- 在线 LLM 报告处理调度、补录报告自动拆分、自动图像定位及报告语义质量验收；手动补录原文不等于启动流水线。
- 真实 CT-RATE TotalSegmentator 结果的完整接入验收仍待数据补充；已有只读层工程验证不代表该数据集结果已全部接入。
- 提示历史主要用于当前会话，不承诺刷新后恢复全部交互提示。
- 没有完整的浏览器 RSS/GPU 峰值和多病例性能基准。
- 磁盘缓存不包含 mask/提示，不代替保存和备份；仍需在线读取元数据，不是离线模式。浏览器可能因配额或存储压力回收缓存。
- 旧 DICOM/VoxTell/SAM/MedGemma 代码与文档的存在，不意味着这些模型在当前 NIfTI 预览全部启用。
